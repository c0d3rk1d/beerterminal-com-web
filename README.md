# BeerTerminal.com

BeerTerminal.com is a terminal-native e-commerce platform that allows customers to browse, discover, and purchase craft beer entirely in the shell through an SSH connection.

Instead of visiting a website or mobile app, users connect directly to the BeerTerminal server using any SSH client. Once connected, they are presented with an interactive text-based shopping experience featuring beer catalogs, brewery profiles, search tools, recommendations, shopping carts, and secure checkout workflows.
